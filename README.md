# OnlineArcade 🎮

OnlineArcade is a browser-based gaming platform in development, planned to feature original 2D and 3D games, multiplayer rooms, parties, and leaderboards.

## Planned stack

- Next.js, TypeScript, Tailwind CSS — website
- Phaser — 2D games
- Three.js — 3D games
- Node.js and Socket.IO — real-time multiplayer

## Roadmap

1. Build the responsive arcade homepage and game catalog.
2. Create the first playable 2D game, **Neon Dash**.
3. Add real-time multiplayer rooms and party codes.
4. Build a 3D racing game.
5. Add profiles and leaderboards.

## Status

🚧 Early development. Games and multiplayer are not available yet.
